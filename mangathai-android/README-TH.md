# MangaThai Mobile (Android)

แอปแปลมังงะอังกฤษเป็นไทยบนมือถือ ทำงานในเครื่องทั้งหมด ไม่ต้องใช้คอมและไม่มีค่า API
มีเบราว์เซอร์ในตัว เปิดเว็บอ่านมังงะแล้วกดปุ่ม **แปล** เพียงครั้งเดียวก็แปลทุกหน้า

- อ่านข้อความด้วย Google ML Kit Text Recognition (โมเดลอยู่ในแอป ใช้ออฟไลน์ได้)
- แปลด้วย Google ML Kit Translate อังกฤษ → ไทย (ดาวน์โหลดโมเดลประมาณ 30 MB ครั้งแรก หลังจากนั้นใช้ออฟไลน์)
- แยกบอลลูนด้วยกฎชุดเดียวกับ MangaThai บนคอม รวมถึงบอลลูนที่ซ้อนกันหรือเชื่อมติดกัน
- บน MangaDex แปลล่วงหน้าทั้งตอน เริ่มจากหน้าที่กำลังอ่าน

## โหมดอ่านข้อความ (เมนู ⋮ → โหมดอ่านข้อความ)

| โหมด | ใช้เมื่อ | ข้อควรรู้ |
|---|---|---|
| **ปกติ** | ค่าเริ่มต้น | ML Kit อย่างเดียว ออฟไลน์ |
| **ตัวตรวจจับมังงะในเครื่อง** | อยากให้แยกบอลลูนและเจอข้อความที่ ML Kit พลาดได้ดีขึ้น โดยยังออฟไลน์ | ใช้โมเดล comic-text-detector (ONNX) โหลดครั้งแรก ~90 MB จาก GitHub แล้วเก็บในเครื่อง ถ้าโหลดหรือรันไม่ได้จะถอยกลับโหมดปกติเอง |
| **Gemini** | ต้องการคุณภาพสูงสุด (หาข้อความ อ่าน แปลในครั้งเดียว เข้าใจบริบท) | ต้องมีเน็ตและ API key ของคุณเอง (เมนู ⋮ → ตั้งค่า Gemini) ภาพหน้ามังงะถูกส่งไป Google ถ้าโควตาหมดหรือเรียกไม่ได้ แอปใช้ตัวแปลในเครื่องแทนสำหรับหน้านั้น |

หมายเหตุ: สมาชิก Gemini Pro/Google AI Pro ในแอปไม่ได้รวมค่า API ต้องสร้าง key ที่ aistudio.google.com/apikey
(มี free tier แต่โควตาต่ำ) ชื่อโมเดลเริ่มต้นคือ `gemini-flash-latest` เปลี่ยนได้ในหน้าตั้งค่า

## ขั้นที่ 1: สร้างไฟล์ APK (เลือกทางใดทางหนึ่ง)

### ทาง A: GitHub Actions (ฟรี ไม่ต้องติดตั้งอะไร)

1. สมัครหรือเข้าสู่ระบบ github.com แล้วกด **New repository** ตั้งชื่อเช่น `mangathai-mobile`
2. ในหน้า repository กด **uploading an existing file**
   แตก zip แล้วลาก **ทุกไฟล์และโฟลเดอร์ข้างใน** `mangathai-android` ไปวาง แล้วกด **Commit changes**
   ต้องมีโฟลเดอร์ `.github` ด้วย ถ้า Windows ซ่อนไว้ ให้เปิด "แสดงรายการที่ซ่อนอยู่" ใน File Explorer
3. ไปที่แท็บ **Actions** ระบบจะเริ่ม build เองภายใน 5–10 นาที
   (ถ้าไม่เริ่ม เลือก **Build APK** แล้วกด **Run workflow**)
4. เมื่อขึ้นเครื่องหมายถูกสีเขียว กดเข้าไปที่งานนั้น แล้วดาวน์โหลด **MangaThai-APK** ด้านล่าง
5. แตก zip ที่ได้ จะได้ไฟล์ `MangaThai.apk`

### ทาง B: Android Studio บนคอม

เปิดโฟลเดอร์ `mangathai-android` ใน Android Studio รอ Gradle sync เสร็จ แล้วเลือก
**Build → Build App Bundle(s) / APK(s) → Build APK(s)** ไฟล์อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

## ขั้นที่ 2: ติดตั้งบน S23 Ultra

1. ส่งไฟล์ `MangaThai.apk` เข้ามือถือ (Quick Share, Google Drive, LINE หรือสาย USB)
2. แตะไฟล์ ถ้าขึ้นว่าไม่อนุญาต ให้แตะ **การตั้งค่า** แล้วเปิด **อนุญาตจากแหล่งนี้** จากนั้นกลับมากดติดตั้ง
3. ถ้า Google Play Protect เตือนแอปที่ไม่รู้จัก ให้เลือก **ติดตั้งต่อไป**
   (แอปนี้ build จากซอร์สโค้ดของคุณเอง จึงยังไม่มีลายเซ็นจาก Play Store)

## ใช้งาน

1. เปิดแอป **MangaThai** หน้าแรกเป็น MangaDex หรือพิมพ์ลิงก์เว็บอื่นในแถบด้านบน
   จาก Chrome หรือ Samsung Internet ก็กด **แชร์ → MangaThai** เพื่อเปิดหน้านั้นในแอปได้
2. เปิดตอนที่จะอ่าน แล้วกดปุ่มสีเขียว **แปล**
   **ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อดาวน์โหลดโมเดลภาษาไทย** (ประมาณ 30 MB)
3. แถบด้านล่างบอกความคืบหน้า หน้าที่อยู่บนจอจะถูกแปลก่อน
   ปุ่ม **ซ่อน** ดูต้นฉบับ • **หยุด** พักการแปล • **✕** ปิดคำแปล
4. กดปุ่ม **แปล** อีกครั้งเพื่อซ่อนหรือแสดงคำแปล
   หลังจากเปิดแปลแล้ว หน้าที่โหลดใหม่จะแปลให้เองจนกว่าจะเลือก "หยุดแปลอัตโนมัติ" ในเมนู ⋮

## แก้ชื่อและคำที่แปลผิด

เมนู **⋮ → ชื่อตัวละคร / คำแทนที่…** ใส่บรรทัดละคำในรูปแบบ `เดิม=ใหม่`

```
Gyro=ไจโร
Johnny=จอนนี่
Corpse Part=ชิ้นส่วนศพศักดิ์สิทธิ์
คุณ=แก
```

- คำอังกฤษ (เช่นชื่อ) จะถูกแทนก่อนแปล ทำให้ชื่อคงที่ทุกหน้า
- คำไทยจะถูกแทนหลังแปล
- บันทึกแล้วหน้าปัจจุบันจะแปลใหม่ด้วยกฎใหม่ทันที

## อ่านแม่นขึ้นในรุ่น 1.2

- อ่านแต่ละบอลลูนซ้ำแบบขยายใกล้ (ทั้งภาพปกติและแบบเพิ่มความคมชัด) แล้วเลือกผลที่อ่านได้คำภาษาอังกฤษจริงมากที่สุด
- แก้คำที่ OCR อ่านผิดด้วยพจนานุกรมในเครื่อง เช่น TOGET → TO GET, IDONT → I DON'T, SITLATION → SITUATION, 155POINTS → 155 POINTS
- ชื่อหรือคำที่ไม่รู้จักและไม่มีวิธีแก้ที่แน่ใจ จะคงไว้ตามเดิม

## รุ่น 1.3

- อ่านแต่ละบอลลูนซ้ำ 3 แบบ: ภาพขยาย, เพิ่มความคมชัด และขาวดำ (ช่วยตัวหนังสือที่มีขอบขาวลอยบนภาพ)
- พจนานุกรมครบขึ้นเป็น 163,000 คำ (รวมรูปคำเต็ม เช่น requests, afterwards) ไม่แก้คำที่ถูกอยู่แล้วให้ผิด
- ต่อคำที่ OCR ตัดเป็นสองท่อนและอ่านผิด: APIER WARDS → AFTERWARDS
- จุด "..." ที่ถูกอ่านเป็นตัวอักษร: MANSIONBOF → MANSION...!, PRESIDENT 00 → PRESIDENT...
- ลบเส้นหางบอลลูนที่ถูกอ่านเป็น "/"
- คำแปลไม่ถูกตัดขอบกล่องอีก

แนะนำให้เพิ่มคำเฉพาะของเรื่องในเมนู ⋮ → ชื่อตัวละคร / คำแทนที่ เช่น `Stand=สแตนด์`

## แปลคุณภาพสูง (ออนไลน์)

เมนู ⋮ → **แปลคุณภาพสูง (ออนไลน์)** ใช้ Google Translate ซึ่งแปลเป็นธรรมชาติกว่าตัวแปลในเครื่อง
ส่งเฉพาะข้อความที่อ่านได้ ไม่ส่งภาพ ถ้าไม่มีอินเทอร์เน็ตจะกลับไปใช้ตัวแปลในเครื่องเอง กดซ้ำเพื่อปิด

## ข้อจำกัด

- ML Kit แปลทีละประโยค ไม่รู้บริบทของเรื่อง จึงแปลตรงตัวกว่า Typhoon บนคอม
  ใช้คำแทนที่ช่วยเรื่องชื่อและคำที่ผิดบ่อยได้
- ข้อความลายมือ ตัวอักษรตกแต่ง หรือเอฟเฟกต์เสียงอาจอ่านไม่ได้
- เว็บที่วาดหน้ามังงะลง canvas หรือป้องกันการดึงภาพยังไม่รองรับ
- คำแปลที่เคยทำแล้วถูกจำไว้ในเครื่อง ล้างได้ที่เมนู ⋮ → ล้างคำแปลที่จำไว้
